## 对架构的累积影响（已吸收进 docs/06）

1. 技术栈冻结：Python 3.11（项目 venv）+ torch cu126 + Ultralytics + Supervision + OpenCV + Gradio + pingouin/statsmodels + matplotlib
2. 户外斜拍下 B2/C 组指标默认 degraded（探索性），主结论只建立在 A 组颗粒曲线上
3. 三层冷启动：YOLOE 开放词汇（零训练）→ 用户标注 30–80 帧微调 → 完整训练（P0 只做前两层入口）
4. D10 的三种实验结构中，**同池双投喂点**是 T05 的新增需求：一段视频内两个 ROI（A 框对照料 / B 框实验料），各自独立出颗粒曲线与指标，比较时作为配对样本处理
