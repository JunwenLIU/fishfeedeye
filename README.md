# fishfeedeye

鱼类摄食行为视频分析工具 —— 面向水产科研的「投喂 → 吃完」全过程录像自动量化系统。

把一段从投喂饲料到饲料被吃完的全过程视频，转换成**可复现、可统计、可写进论文**的量化指标，
用于比较不同饲料 / 添加剂（诱食剂）的诱食性。

## 核心能力

- **视频接入与预处理**：非对称采样、稳像、ROI / 透视标定、参考区噪声扣除、投喂前基线段检测
- **双轨检测计数**：YOLOE 开放词汇 + SAHI 切片推理 ‖ 面积积分；消失三分类（被吃 / 漂出 / 丢失）
- **指标计算**（仅以单段视频可得者）：剩余颗粒数—时间曲线、T50/T90 清空时间、消耗半衰期、
  首次摄食潜伏期、相对偏好系数 RP、活跃度曲线与 AUC、13 个质量信号 + 降级矩阵
- **两组统计比较**：Welch t 检验 + Mann–Whitney + Cohen's d + 95% CI，含七条比较前一致性校验
- **论文就绪导出**：逐帧 CSV、指标报告、人工校正留痕、可复现参数包
- **诚实的精度边界**：不可用指标一律输出 `unavailable + reason`，绝不用 0 冒充「测出 0」

## 环境要求

- Python 3.11 + CUDA 12.6（本机 RTX 3060 Ti 实测 YOLOE 推理 ≈ 0.22 s/帧）
- 依赖安装：`pip install -r requirements.txt`
- 运行：
  - 命令行：`python scripts/run_cli.py --video <视频> --config configs/default.yaml`
  - 界面：`python -m src.app.main`

## 重要约束（使用须知）

- 单段视频在**原理上无法产出** FCR / SGR / 增重率等跨天称重指标，本工具不提供此类估算。
- T100（全部吃完时刻）受整数颗粒计数精度限制（理论误差界 ≈ ±12.5 s），主证据请取 **T50 / T90**。
- 沉性料在纯视频中无法区分「被吃掉」与「沉底消失」，建议使用浮性膨化料或布设投喂框。
